Atividade Avaliativa - Estruturas de Dados em C

O objetivo da atividade é praticar manipulação de listas encadeadas utilizando linguagem C.

Desenvolvi implementações envolvendo:

- Inserção em posição específica
- Busca por valor
- Inversão de lista
- Divisão de lista
- Playlist usando lista circular duplamente encadeada

---

Estrutura dos arquivos

- lista_encadeada.c
- playlist_circular.c

---

Requisitos utilizados

- Linguagem C
- stdio.h
- stdlib.h

---

Funcionalidades implementadas

Lista Encadeada

- Inserção em posição específica
- Busca de valores
- Inversão da lista
- Divisão da lista em duas partes

Playlist Circular

- Adicionar músicas
- Navegar para próxima música
- Voltar música anterior
- Exibir playlist
- Mostrar total de músicas

---

Como rodar

```bash
gcc lista_encadeada.c -o lista

gcc playlist_circular.c -o playlist
